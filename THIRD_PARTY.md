# Происхождение компонентов

## ObsidianDataWeave

Каталог `dataweave/` содержит локально доработанный снимок проекта
[howdeploy/ObsidianDataWeave](https://github.com/howdeploy/ObsidianDataWeave).
Это основа импорта документов, атомарных заметок, Wiki и поиска по vault.

Исходная лицензия: MIT, Copyright (c) 2026 ObsidianDataWeave Contributors.
Полный текст сохранён в `dataweave/LICENSE` и корневом `LICENSE`.

Локальные доработки включают атомарную запись Wiki, проверку входного снимка,
переносимый журнал обработанных источников и сокращение контекста компиляции.
Снимок взят из работающей установки при подготовке VaultGoblin 30.10.2026;
он не объявляется неизменённой upstream-версией.

## Общие знания Codex

Каталог `codex-shared-knowledge/` содержит отдельный навык экспорта и поиска
знаний между устройствами. Он не входит в исходный ObsidianDataWeave.
В VaultGoblin включена версия с регрессиями для ограничения ответа, фрагментов
поиска, путей с пробелами и проверки источников из локального индекса.
