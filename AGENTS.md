# VaultGoblin

Пиши по-русски. Сохраняй простую структуру из двух независимых компонентов.

- Для `dataweave/` следуй его `AGENTS.md` и соответствующим контрактам в `rules/`.
- Для `codex-shared-knowledge/` следуй описанию навыка в `SKILL.md`.
- Личные настройки, авторизацию, заметки, экспорты и индексы не добавляй в Git.
- Проверки выполняй на временных данных; внешнюю модель и реальный vault используй
  только в рамках явного поручения пользователя.
- Команды проверки приведены в README. Сохраняй исходную лицензию и сведения об авторстве.
