# Автоэкспорт и хуки

Русский | [English](automation_en.md)

## Настройка

Сначала выполните [установку навыка](usage.md), затем из корня клона:

```bash
python3 skills/codex-shared-knowledge/scripts/shared_knowledge.py install-hooks
```

На Windows используйте `python`. Команда добавляет в `CODEX_HOME/hooks.json`
два обработчика. Существующие хуки сохраняются; прежний файл копируется в
`CODEX_HOME/backups/shared-knowledge-hooks/`. Повторная установка не создаёт дубли.

| Событие | Действие |
|---|---|
| `Stop` | Тихий экспорт в фоне после завершения хода |
| `SessionEnd` | Последний синхронный экспорт, тайм-аут 3 секунды |
| Резервный таймер | Экспорт каждые 5 минут для более поздних изменений памяти |

Обработчики запускают установленный `shared_knowledge.py export --quiet` тем же
Python, которым выполнялась установка хуков. Они не вызывают модель, не читают
транскрипт или сообщение пользователя и не дописывают знания от себя.
Успешный запуск ничего не выводит. Если другой экспорт уже работает, тихий вызов
завершается успешно; ошибки файлов и настроек остаются видимыми.

Установка резервной задачи Windows:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\skills\codex-shared-knowledge\scripts\install_export_task.ps1 -PythonPath (Get-Command python.exe).Source
```

Для Linux сохраните имеющийся пользовательский systemd timer и выставьте интервал
5 минут. Команда сервиса: местный Python и полный путь к скрипту клона с `export`.
Лог задачи Windows: `CODEX_HOME/shared-knowledge-export.log`.

## Доверие Codex

Codex требует проверить и доверить точные определения новых хуков через `/hooks`.
До этого он их пропускает. VaultGoblin не обходит этот механизм и не меняет
`trusted_hash`. После установки откройте новый чат и проверьте два обработчика
с подписью `VaultGoblin: export shared knowledge`.
[Официальная документация хуков](https://learn.chatgpt.com/docs/hooks).

Нативная память обновляется в фоне, поэтому конец чата не означает, что новые
файлы уже готовы. Отдельного `MemoryUpdated` в документированном списке событий
нет; таймер подхватывает поздние изменения.
[Документация памяти Codex](https://learn.chatgpt.com/docs/customization/memories).

## Чтение знаний

Контекст подбирает навык по задаче: один поиск в знакомом проекте, при повторной
ошибке или вопросе о прежнем решении. Простые правки и общие вопросы поиска
не требуют. Новые данные другого устройства обнаруживаются при очередном поиске.

Хуки не загружают заметки в начало каждого чата и не классифицируют сообщения.
Это сохраняет общий слой в рамках `Codex Knowledge/devices` и ограничивает
расход контекста. Для ручной проверки используйте `recall` или `search`.
